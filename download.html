How do I install the Android app?
  1. Tap Download APK and wait for it to finish.
  2. Open the file from your notifications or Downloads.
  3. If Android asks, allow Install unknown apps for your browser, then go back and tap Install.
  4. Open Remix Nexus and log in — you're set.
How do I install the Windows app?
  1. Click Download for Windows and open the .exe when it finishes.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. This appears because the app is new and not yet code-signed.
  3. Follow the installer. Remix Nexus opens and adds a Start-menu shortcut.
  4. Updating? Just run the new installer — it replaces the old version.
How do I run the Linux app?
  1. Download the .AppImage file.
  2. Make it runnable: right-click → Properties → Allow executing as a program, or run chmod +x Remix.Nexus-1.0.1.AppImage in a terminal.
  3. Double-click it (or run ./Remix.Nexus-1.0.1.AppImage).
  4. If it won't start on a newer distro, install libfuse2 and try again.
