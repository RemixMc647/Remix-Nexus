REMIXVERSE — REMIX NEXUS FILE SET

ROOT-DIRECTORY LAYOUT
All project files are kept together in the root directory. There is no public/ folder.

Main files:
- index.html       Landing page
- play.html        Playable game interface
- legacy.html      Past lives and achievements
- guide.html       Instructions
- account.html     Registration, login and account status
- styles.css       Shared responsive visual theme
- game.js          Game UI/controller
- storage.js       Local cache and authenticated cloud-save sync
- data.js          Game content
- engine.js        Game rules
- fx.js            Animation and sound effects
- layout.js        Shared header/footer and Remix Nexus link
- server.js        Express API, account sessions and static file server
- package.json     Node dependencies and start command
- render.yaml      Optional Render service configuration
- .env.example     Example environment variable names; do not put real secrets here

DEPLOYMENT
1. Keep all files in the same project root.
2. Use Node.js 20 or newer.
3. Build command: npm install
4. Start command: npm start
5. Configure MONGODB_URI and SESSION_SECRET as private environment variables in your host dashboard; set NODE_ENV=production.
6. Open /api/health to check the service and /account.html to test registration/login.

IMPORTANT
- The app is not deployed automatically. You must deploy it yourself and configure MongoDB Atlas.
- Keep all browser files and the API on the same HTTPS origin for session cookies and cross-device cloud saves.
- This package has not had a live end-to-end deployment test. Test registration, login, save/load, logout and another-device login after deployment.
- Email verification, password recovery and account deletion are not included yet.
